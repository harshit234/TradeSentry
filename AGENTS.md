# Agent Rules — MANDATORY

1. Never invent, modify, or interpret UCP 600 rules.
2. Never execute or simulate settlement.
3. Never call tools outside the approved allow-list.
4. Every compliance finding needs a rule ID, UCP article, expected value, actual value, and evidence.
5. Never log raw document content, secrets, tokens, signed URLs, or PII.
6. Risk scores are investigation signals, not legal findings or proof of fraud.
7. All thresholds are prototype demo values, not regulatory standards.
8. Human approval is required for every consequential action.
9. Agents read case state and never mutate the database directly.
10. FCSS is downstream settlement infrastructure; this system does not control it.
